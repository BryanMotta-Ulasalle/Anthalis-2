# Actualización de imágenes

Se incorporaron 21 imágenes individuales recreadas con IA de 1254 × 1254 píxeles,
exportadas a WebP para la web. La portada utiliza Abrazos de flor.
Las tarjetas, portada y miniaturas del pedido usan encuadre completo y centrado.

Las seis colecciones utilizan las nuevas imágenes individuales, incluida Suspiros.

Validación: compilación Vite correcta, ocho pruebas existentes aprobadas,
21 imágenes del catálogo válidas de 1254 × 1254 y portada de la misma resolución.
No se completó inspección visual en navegador: el control de Chrome se detuvo
porque no pudo identificar con seguridad la URL activa.

Los originales PNG de los 21 arreglos se conservan en la carpeta local
../anthalis-recursos/imagenes-ia/individuales, fuera del repositorio. El ZIP contiene los recursos
WebP y el código actualizado, además de dist listo para alojamiento estático.
